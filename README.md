# 🧪 Stavo Lab | Genshin Impact Tracker

> 🚀 Um hub interativo desenvolvido de fã para fã, unindo tecnologia, organização de dados e a paixão pelo universo de Teyvat!

---

## 💡 Sobre o Projeto
O **Stavo Lab** nasceu como um projeto prático para consolidar e elevar meus conhecimentos em **Desenvolvimento Web Front-End (HTML, CSS e JavaScript)**. 

A ideia central foi construir uma ferramenta fluida, intuitiva e funcional que servisse de apoio para a comunidade de **Genshin Impact**, aplicando na prática conceitos de estruturação de dados, manipulação de DOM e otimização de interface.

✨ **Principais aprendizados aplicados:**
* Estruturação limpa e modular de arquivos
* Lógica de programação dinâmica em JavaScript
* Organização e exibição de grandes volumes de assets
* Experiência do usuário (UX/UI) focada em navegabilidade

---

## 🛠️ Tecnologias Utilizadas
* **HTML** (Estrutura semântica)
* **CSS** (Estilização e layout)
* **JavaScript** (Lógica e interatividade)
* **GitHub Pages** (Hospedagem e deployment)

Este projeto é uma iniciativa **estritamente educacional, pessoal e sem fins lucrativos**.

* **Uso Não Comercial:** O Stavo Lab não possui qualquer tipo de monetização, anúncios ou cobranças.
* **Propriedade Intelectual:** Todos os direitos sobre nomes, marcas registradas, artes, ícones e assets do jogo pertencem exclusivamente à **Cognosphere / HoYoverse**.
